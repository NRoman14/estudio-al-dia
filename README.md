# Estudio al Día

Estudio al Día es un proyecto de aplicación web en Laravel para organizar tareas universitarias. Cada estudiante podrá crear, editar y eliminar sus tareas, además de marcarlas como completadas.

## Sugerencias con Grok

Desde el detalle de una tarea, el botón **Sugerir pasos** usará Grok para generar tres acciones concretas a partir del título y la descripción de la tarea. Por ejemplo, para preparar una exposición de Base de Datos, puede sugerir definir el tema, ordenar los contenidos y preparar la primera diapositiva.
